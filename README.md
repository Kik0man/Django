# Проект написанный при помощи Django
## Первая часть проекта - это настройка и ознакомление с функциями
### 
1. Был создан и настроен проект
2. Создали приложение catalog
3. Создали два шаблона home.html и contacts.html
4. Реализовали контроллеры

Запустить сервер можно с помощью команды `python3 manage.py runserver`, после чего 
перейти по ссылке которая выведется в терминале или перейти по адресу http://127.0.0.1:8000/home/

## Вторая часть проекта - это расширение функционала при помощи баз данных
###
1. Добавили и настроили settings и pgAdmin
2. Создали модели по требованиям
3. Провели миграции
4. Создали суперпользователя
5. Поработали с инструментов shell
###
Для корректной работы необходимо использовать свои данные `.env`
Запустить сервер можно с помощью команды `python3 manage.py runserver`, после чего 
перейти по ссылке которая выведется в терминале или перейти по адресу http://127.0.0.1:8000/admin/
