# Проект на Django: интернет-магазин, блог и сервис email-рассылок

Проект состоит из трёх основных приложений:
- `catalog` – управление товарами и категориями
- `blog` – блоговые статьи с подсчётом просмотров
- `mailing` – сервис создания и отправки email-рассылок с контролем доступа и статистикой

## 1. Первая часть – базовый функционал

1. Создан и настроен проект Django.
2. Добавлено приложение `catalog`.
3. Реализованы шаблоны `home.html` и `contacts.html`.
4. Написаны простые контроллеры для отображения страниц.

Запуск сервера:  
`python manage.py runserver`  
Сайт доступен по адресу http://127.0.0.1:8000/

## 2. Вторая часть – работа с базой данных

1. Подключена PostgreSQL, настройки вынесены в `.env`.
2. Созданы модели `Category` и `Product` в приложении `catalog`.
3. Выполнены миграции.
4. Создан суперпользователь.
5. Проведена работа в Django shell.

Для работы необходимо заполнить `.env` файл своими данными.  
Админ-панель: http://127.0.0.1:8000/admin/

## 3. Каталог товаров (`catalog`)

- Полный CRUD для продуктов и категорий.
- **Валидация формы продукта**:
  - запрещённые слова в названии и описании (казино, криптовалюта, биржа, дешево, бесплатно, обман, полиция, радар);
  - цена только положительная, не более 1 000 000.
- **Загрузка изображений**: форматы JPEG/PNG, размер до 5 МБ, автоматическое сжатие.
- **Права доступа**:
  - владелец может редактировать/удалять свой продукт;
  - модератор может отменять публикацию и удалять чужие продукты.
- **Кеширование**: список продуктов и детальная страница кешируются через Redis.

## 4. Блог (`blog`)

- CRUD для статей.
- Автоматический счётчик просмотров.
- Отправка email-уведомления при достижении 100 просмотров.
- В публичном списке отображаются только опубликованные статьи.

## 5. Сервис рассылок (`mailing`) – **новое приложение**

### Функциональность

- Управление **получателями** (email, ФИО, комментарий).
- Управление **сообщениями** (тема, тело письма).
- Управление **рассылками**:
  - даты начала и окончания;
  - динамический статус (`Создана`, `Запущена`, `Завершена`);
  - привязка сообщения и списка получателей.
- **Отправка рассылок**:
  - через веб-интерфейс (кнопка «Запустить отправку»);
  - через кастомную management-команду:  
    `python manage.py send_mailing <mailing_id>`
- **Логирование попыток**:
  - модель `MailingAttempt` фиксирует время, статус (`Успешно`/`Не успешно`) и ответ почтового сервера.
- **Статистика**:
  - главная страница показывает общее количество рассылок, активных рассылок и уникальных получателей;
  - страница «Отчёт» выводит количество успешных и неуспешных попыток по каждой рассылке.

### Роли и права доступа

- **Обычный пользователь**:
  - видит и управляет только своими получателями, сообщениями, рассылками;
  - может отправлять свои рассылки.
- **Менеджер** (группа `Менеджеры`):
  - просмотр всех получателей, сообщений, рассылок и попыток;
  - право отключать любые рассылки (`can_disable_mailing`);
  - возможность блокировать пользователей (через админку или интерфейс).

Группа и права создаются автоматически командой:  
`python manage.py init_manager_group`

### Кеширование

- Настроено серверное кеширование через Redis.
- Главная страница кеширует статистику на 5 минут.

## Установка и запуск

```bash
# Клонирование репозитория
git clone <repository-url>
cd <project-name>

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения (создайте .env файл)
# Пример содержимого .env:
# SECRET_KEY=your-secret-key
# DEBUG=True
# NAME=your_db_name
# USER=your_db_user
# PASSWORD=your_db_password
# HOST=localhost
# PORT=5432
# EMAIL_HOST_USER=your-email@gmail.com
# EMAIL_HOST_PASSWORD=your-app-password

# Применение миграций
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser

# Создание группы "Менеджеры" и назначение прав
python manage.py init_manager_group

# (Опционально) Загрузка тестовых данных для каталога
python manage.py loaddata products.json

# Запуск сервера разработки
python manage.py runserver
