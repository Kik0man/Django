# Django Проект - Интернет-магазин и Блог

### Каталог товаров
- CRUD операции с продуктами и категориями
- **Валидация форм**: запрещенные слова (казино, криптовалюта, биржа, дешево, бесплатно, обман, полиция, радар)
- **Проверка цены**: только положительные значения
- **Загрузка изображений**: JPEG/PNG до 5MB

### Блог
- Полный CRUD для статей
- Автоматический подсчет просмотров
- Email-уведомление при 100 просмотрах
- Только опубликованные статьи в списке

## Установка

```bash
# Клонирование
git clone <repository-url>
cd <project-name>

# Установка зависимостей
pip install django psycopg2-binary pillow python-dotenv

# Настройка БД и миграции
python manage.py migrate

# Загрузка тестовых данных (опционально)
python manage.py loaddata products.json

# Создание суперпользователя
python manage.py createsuperuser

# Запуск
python manage.py runserver
